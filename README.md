# MaqamFlow — Gizlilik Politikası

Bu depo **yalnızca** MaqamFlow'un gizlilik politikası sayfasını barındırır.

Google Play gizlilik politikası için herkese açık bir adres istiyor; dosya kabul etmiyor. Uygulamanın kaynak kodu ayrı ve **private** bir yerde duruyor; burada yalnızca zaten herkese açık olması gereken metin var.

Yayındaki adres: https://abdussamed6110.github.io/MaqamFlow-gizlilik/

Metni güncellemek gerekirse kaynağı proje içindeki `tools/gizlilik_uret.py`:

```bash
python3 tools/gizlilik_uret.py --mod firebase
```

Üretilen `docs/magaza/gizlilik/gizlilik_firebase.html` dosyasını buraya `index.html` olarak kopyalayın.
